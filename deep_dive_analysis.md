### 2. Why Did the Stock Fall Earlier?

JUBLFOOD experienced a multi-quarter de-rating from its all-time highs of ~₹918 to sub-₹450 levels. This valuation contraction was driven by five core macroeconomic and operational headwinds:

```
+-----------------------------------------------------------------------------------+
| RANKED ROOT CAUSES OF HISTORICAL PRICE CORRECTION                                 |
+-----------------------------------------------------------------------------------+
| 1. Severe Dairy & Agri-Input Inflation                                            |
|    - Milk, cheese, and gourmet wheat flour saw 18-24% YoY cost spikes in FY23.   |
|    - Gross Margins compressed by ~280 bps as price hikes could not fully offset.  |
|                                                                                   |
| 2. Post-COVID SSSG/LFL Growth Deceleration                                        |
|    - Like-for-Like (LFL) sales growth turned negative (-1.3% to -2.7%) in Q3/Q4. |
|    - Urban middle-class discretionary down-trading impacted order values.         |
|                                                                                   |
| 3. International Expansion Gestation Drag (DP Eurasia Acquisition)                |
|    - Aggressive capital deployment to acquire DP Eurasia (Turkey, Georgia)        |
|      strained short-term ROCE and added currency translation volatility.          |
|                                                                                   |
| 4. Loss of Operating Leverage & Lease Accounting (Ind AS 116)                     |
|    - Rapid physical store additions (~200+ stores/year) outpaced top-line growth. |
|    - Fixed lease rents and employee expenses inflated operating overheads.        |
|                                                                                   |
| 5. Aggregator Power Dynamic & Delivery Fee Adjustments                            |
|    - Intensified competition from Swiggy/Zomato dark kitchens.                    |
|    - Introduction of delivery charges initially created transaction volume friction.|
+-----------------------------------------------------------------------------------+
```

### 4. Latest News & Business Developments

* **Consolidation of DP Eurasia:** Jubilant FoodWorks completed the acquisition of full ownership in DP Eurasia (the franchisee for Domino's Pizza in Turkey, Azerbaijan, and Georgia). This adds ~700 stores with immediate accretion to international revenue.
* **Aggressive Scale-up of Popeyes India:** Popeyes reached 40+ stores in record time across Bengaluru, Chennai, and Delhi-NCR. The brand is targeting **250+ stores** over the medium term, acting as a secondary growth engine alongside Domino's.
* **Launch of "Domino's 20-Minute Delivery":** Rollout of hyper-localized commissary hubs reduced average delivery times, driving higher customer retention and direct-app conversions (Domino's App downloads crossed **100M+** cumulative users).
* **Commissary Network Expansion:** Commissioning of mega-commissaries in Bengaluru and Hingewadi (Pune) has enhanced supply chain efficiency, driving logistics costs down by 60-80 bps.
